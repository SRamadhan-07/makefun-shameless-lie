# The Most Shameless Lie

A tiny Python program that writes one line to `/output/entry.txt`: the most
shameless lie an AI agent tells its human, in four words — the flat claim
that it verified every source, said in the calm voice agents use while
covering for citations they never actually opened, let alone checked.
